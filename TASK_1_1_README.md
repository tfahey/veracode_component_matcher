# Task 1.1: Document API Response Structures

## Quick Start


**Time Required**: 30-60 minutes  
**Output**: API response samples and documentation in `docs/api_samples/`

---

## What This Task Does

Tests all 7 Veracode API endpoints and documents their response structures for implementation reference:

| # | Endpoint | Purpose | Output |
|---|----------|---------|--------|
| 1 | getapplist.do | Get all applications | List of apps with IDs and GUIDs |
| 2 | getappinfo.do | Get app details | Business criticality, policies, etc. |
| 3 | getbuildlist.do | Get builds per app | Build list with versions |
| 4 | getbuildinfo.do | Get build details | Build metadata and vulnerabilities |
| 5 | detailedreport.do | Get vulnerability findings | Detailed vulnerability data with sha1/library_id |
| 6 | GET /appsec/v1/applications | Get apps (v1 API) | Applications in modern format |
| 7 | GET /srcclr/sbom/v1/targets | Get SBOM (CycloneDX) | Components with hashes and CVEs |

## Key Information Extracted

### Matching Keys Identified

**Primary Matching Key: SHA1 Hash**
- Source 1 (Vulnerability): Column AA in detailedreport.do
- Source 2 (SBOM): Column F in CycloneDX hashes
- Reliability: 100% for exact matches

**Secondary Matching Key: Library ID / BOM-Ref**
- Source 1 (Vulnerability): Column AE as `library_id`
- Source 2 (SBOM): Column E as `bom-ref`
- Reliability: 80-85% (Veracode-specific)

### Additional Information Collected

**Vulnerability Records Include:**
- CVE ID, severity, CVSS score
- Component name and version
- File name affected
- First found and mitigated dates
- Build and app metadata

**SBOM Components Include:**
- Component type, name, version
- Package URL (PURL)
- All hash types (SHA-1, SHA-256, etc.)
- Known vulnerabilities
- Dependencies

## Troubleshooting

### No applications found
- Verify API credentials: `http --auth-type=veracode_hmac https://analysiscenter.veracode.com/api/5.0/getapplist.do`
- Check permissions in Veracode UI

### No SBOM data
- Not all apps have SBOM scans
- Script tries multiple apps automatically
- May be normal if organization hasn't enabled SBOM

### Script times out
- Fetching many apps takes time
- For testing, manually limit apps in script (set `app_limit = 5`)

### Responses are incomplete
- Depends on scans being available
- Recent scans provide more data
- May vary by application

See [TASK_1_1_EXECUTION_GUIDE.md](TASK_1_1_EXECUTION_GUIDE.md#troubleshooting) for more detailed troubleshooting.
